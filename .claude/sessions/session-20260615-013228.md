## Key findings
- **`a:hover` repainted ALL anchor-button text pink** (the primary CTA went pink-on-pink). Root cause: global `a:hover { color: var(--action-accent) }` hitting `.btn` anchors. Fixed with `a:not(.btn):hover`. **Gotcha:** the design tokens ship twice — `tokens.css` AND the minified `tailwind.generated.css` — so a token-layer CSS edit doesn't take effect until `npm run build:css` regenerates the bundle.
- **`ch` units resolve against the element's own font-size** — a `max-width: 40ch` on a 16px header div was throttling a 36px heading to ~320px (4-line wrap). Watch for this.
- **Preview screenshots come back blank for deep-scroll positions on long pages** (homepage teaser, page foots) — partly scroll-reveal opacity, partly a capture-tool limit. Verified those structurally via `preview_eval` instead; near-top sections screenshot fine.
