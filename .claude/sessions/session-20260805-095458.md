### Decisions
- **Article FAQPage JSON-LD is derived, not authored** (#43): extracted at build time from each article's own question-led H2s + the answer prose directly beneath (scripts/hub-utils.js), so the schema structurally cannot drift from visible content — chosen over frontmatter-authored FAQ blocks, which would have recreated the hand-sync problem B5 had to reconcile on the FAQ/offering pages. Convention source: the ax-seo-aeo-layer skill (2–4 Q&As, 40–80 word answers, natural question phrasing). All 32 generated pairs eyeballed post-build: complete sentences, verbatim article prose, 29–83 words, zero JSON parse failures.
- **Sitemap offering URLs derive from offerings.json live slugs** — same no-drift principle as Check #10. The five service-line pages being absent from the sitemap is exactly the drift this prevents recurring.
- **sitemap lastmod = last git commit touching the built page** (dirty files fall back to today — accurate, since a dirty file was just rewritten by the build). The old behaviour stamped every static URL with the build date ("changed today, every build" — a signal search engines learn to ignore); article entries used frontmatter `published`, which understated freshness after content refreshes (#93 rewrote five articles while lastmod kept asserting their original publish dates — the actual stale-lastmod failure #40 flagged). Verified byte-stable: rebuilding immediately after commit produces zero diff.
- **llms.txt carries no prices** — offering names/links/guarantee yes, numbers no (drift risk in a hand-maintained file; each offering page publishes current pricing). Also states the brand-spelling rule explicitly ("Accelerator X, two words, no hyphen — the domain is the only hyphenated form") as entity-disambiguation input, without naming the namesake sites.
- **/quiz and /quiz/* 301 to the quiz subdomain ROOT**, not the historical deep path — the deep path now 404s on the subdomain itself (verified live 2026-08-05).
- **Brand-string normalisation inside a real testimonial quote** (testimonials.json, David Carry / Track Record Coaching): treated "Accelerator-X" → "Accelerator X" as typesetting of our own brand name within a quote we render, not a change to the speaker's words. Flag to Andy if he disagrees.
